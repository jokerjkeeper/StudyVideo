# 《原神》部分渲染效果分析｜非官方觀察

原文（GameRes 游資網，2020-09-18）｜[技术分享 |《原神》部分渲染效果分析（非官方）](https://www.gameres.com/874408.html)

GameRes 經作者 Lucifer 授權轉載。作者從畫面辨識效果，再提出能重現相近畫面的技術。本筆記以「可能的做法」記錄推測，遊戲正式實作與效能數據需以開發團隊資料為準。[作者原始知乎文章《<原神>部分效果的个人理解》](https://zhuanlan.zhihu.com/p/246531456)

## 角色與場景光影

| 技術 | 解決的問題 | 文章提出的可能做法 |
| --- | --- | --- |
| 分距離的烘焙光照 | 近處需要清楚的靜態陰影，遠景若保留同樣精度會增加資產量與載入壓力。 | 作者由遠、中、近景陰影細節的差異，推測可用不同精度的 Lightmap，極遠處再改為低模頂點色。具體分級屬於推測。 |
| 光照探針與陰影邊界 | 移動角色和未烘焙到 Lightmap 的草，走進建物陰影時仍需要變暗。 | 建議在陰影邊界內外配置探針，讓角色和草依位置取得不同明暗的間接照明，使兩側的亮度差更清楚。 |
| 局部投影式角色陰影 | 角色需要在草與地面投下可辨識的陰影，又要限制投影範圍與成本。 | 提出以沿光向的正交相機繪製角色遮罩，再投到指定接收面。這種方案的接收面可控，但角色間互投與雙重陰影需要另行處理。 |
| 世界座標的移動雲影 | 雲影需要在不同地形表面連續移動。 | 用世界座標 XZ 取樣一張平移的噪聲遮罩，讓地表共用同一片明暗圖案。若要避開室內區域，作者另提出以垂直深度比較判斷遮蔽。 |
| 兩張臉部明暗控制圖 | 鼻翼和臉部三角區在不同光向下需要不同的明暗切換順序，單張固定遮罩容易在另一側出現不自然的結果。 | 作者示範分別繪製受光側和背光側的控制圖，依光向相對臉部的左右方向選擇取樣，再調整局部明暗閾值。 |

## 植被、透明特效與遠景

| 技術 | 解決的問題 | 文章提出的可能做法 |
| --- | --- | --- |
| GPU Instancing 繪製草地 | 密集草叢若逐株提交繪製會增加渲染提交成本。 | 批次繪製共用網格與材質的草，各實例提供自己的位置與變化參數。作者以自己的 Unity 植被測試比較不同提交方法，結果取決於場景與硬體。 |
| 草地燃燒的材質變化 | 需要讓玩家看出火的作用範圍和草地枯萎，不必逐株求解燃燒。 | 依技能範圍放置火焰粒子，草 Shader 在範圍內混入枯萎色，依時間裁切草葉，並可用噪聲打散裁切邊緣。 |
| 相機深度控制透明交界 | 水面貼岸、火焰粒子碰到地面時，直接裁切會出現生硬交線。 | 以場景深度和透明片元深度的差做淡化，讓交會處逐漸消失。水下扭曲則可取樣已繪製的背景，使用偏移座標模擬變形。 |
| 粒子雲海與距離／高度霧 | 遠景需要明確的前後層次，雲海也要有足夠的空間感。 | 以多層粒子面片和天空背景堆出雲海，再用距離霧與高度霧建立景深層次。面片在部分觀察角度可能顯露平面感。 |
| 地形分塊與不同精度的遠景 | 開放世界要顯示很遠的地形，同時限制記憶體使用與繪製量。 | 把地形與相關資源按區塊管理，載入玩家附近的細節，視野內更遠處採較低精度。作者也列出 LOD、遮擋剔除與 Impostor 等可選策略，區塊交界仍需處理幾何與光影接縫。 |
