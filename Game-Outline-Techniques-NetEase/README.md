## 背殼外擴與線寬

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 背面法線外擴 | 需要隨模型視角更新的剪影輪廓。 | 再繪製一層沿法線外擴的背面，剔除正面，讓原模型遮住外殼中央，露出的部分成為輪廓。代價是增加一次幾何繪製。 |
| 裁切空間偏移與解析度補償 | 固定世界外擴會近粗遠細，寬螢幕也可能讓水平與垂直線寬不同。 | 在裁切空間偏移 XY，以齊次座標 W 補償透視除法，再依畫面寬高比調整偏移。若遠處小物件被固定寬度的線蓋住，可加距離衰減。 |
| 非等比縮放下的法線轉換 | 模型只拉長其中一軸時，直接用位置變換處理法線會扭曲外擴方向。 | 用模型視圖矩陣的逆轉置轉換法線，再投影到螢幕方向，以維持法線與表面的正交關係。 |
| 另存平滑法線 | 硬邊或接縫可有同位置、不同法線的頂點，外擴時容易裂開。 | 離線為描邊建立平滑方向並存入網格附加資料，著色仍用原本的硬邊法線。 |

## 可交叉比對的公開案例

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 頂點控制外線與 UV 本村線 | 外輪廓與模型表面的衣服縫線需要不同的控制。 | 《罪惡裝備 Xrd》示範以距離和頂點資料控制背殼輪廓，內線則對齊貼圖 U／V 軸並以 UV 覆蓋控制粗細。 |
| 以純色區域做螢幕空間邊緣偵測 | 對完成畫面直接偵測容易把材質花紋「勾」成假輪廓。 | 雷宇航示範先用純色區分預定區域，再以 Sobel 找交界，能控制哪些區域才出線。 |
