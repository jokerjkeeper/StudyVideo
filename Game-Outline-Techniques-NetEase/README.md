## 從模型產生輪廓

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 背面外擴 | 角色轉動時，需要隨模型更新的外輪廓。《XIII》是文中用來說明的早期案例。 | 正常畫模型，再沿頂點法線外擴，以正面剔除只畫外殼背面。原模型遮住外殼中央，只留下外緣。可程式化管線可在頂點著色器做外擴，仍需多一次繪製。 |
| 局部深度偏移 | 髮束和凹凸交錯處可能出現美術不希望看到的線。 | 在指定頂點給描邊深度偏移，使多餘的外殼被主模型遮住。原文以《罪惡裝備 Xrd》把這個控制存進頂點色 B 通道為例。 |
| 為描邊另存平滑法線 | 硬邊或髮束接縫上，同位置的頂點可能朝不同方向外擴，使輪廓斷裂。 | 對同位置的頂點平均方向，另外儲存給描邊使用，美術著色仍可保有原法線。《藍色協議》的案例也提到獨立輪廓模型，可按髮型更精細地控制結果。 |
| 局部線寬與線色 | 全角色使用同一線寬，筆觸難以反映不同部位的重要性。 | 使用頂點資料乘上外擴量來控制線寬，《罪惡裝備 Xrd》採用這類做法。文中另建議以頂點資料或專用貼圖控制線色。 |
| Fresnel 掠視角邊緣 | 某些圓滑形體只需要簡單的邊緣暗帶，不必為它另外畫背殼。 | 用法線與視線的點積選出掠視角區域。球面較容易得到連續的邊，但平面上的法線近乎一致，一轉到側面就可能整片觸發。 |

## 模型內部折線與離線筆觸

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 預提取折線與 Geometry Shader | 背面外擴主要得到外輪廓，容易漏掉裝甲或機械表面的內部尖銳折線。 | 米哈遊 Unite 2018 分享先提取需要的邊並存為額外 Mesh，再用 Geometry Shader 畫線。Ashley 另外討論把邊擴成四邊形以調線寬，並指出 Geometry Shader 的效能與平台相容取捨。 |
| Compute Shader 與軟體光柵化 | 仍想保有內折線的控制力，並探索 Geometry Shader 以外的輸出路徑。 | Ashley 提出用 Compute Shader 處理線段再做軟體光柵化作為研究方向。文章未提供成品或效能量測。 |
| Blender Freestyle | 影視線稿需要按線型、可見性和筆觸分開設計。 | 每幀找出候選邊，以 Line Set 篩選要畫的線，再以 Line Style 設定顏色、虛實和質感。這是離線渲染流程，可用來對照即時線條系統的取捨。 |
