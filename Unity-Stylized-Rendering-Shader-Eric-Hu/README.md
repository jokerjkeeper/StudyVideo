# Unity 風格化 Shader｜卡通光照、印刷網點與排線

原文（Eric Hu，2022-04-28）｜[在Unity實現風格化渲染的Shader](https://medium.com/@eric.hu/%E5%9C%A8unity%E5%AF%A6%E7%8F%BE%E9%A2%A8%E6%A0%BC%E5%8C%96%E6%B8%B2%E6%9F%93%E7%9A%84shader-c5a376ab8f85)

作者分享自己在 Unity 製作的風格化 Shader。筆記依作者網站的版本整理。文中的 URP 描邊接法對應作者當時的實作。[作者網站版本](https://erichu33.github.io/zh-tw/posts/2022-04-28-achieve-npr-in-unity/)

## 光照與輪廓

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| Ramp 漫反射 | Lambert 的連續明暗難以直接控制色階、分界位置和陰影配色。 | 以法線與光向的點積 N·L 查詢 Ramp 貼圖，讓貼圖控制色階和顏色。作者也示範把 Ramp 結果與 PBR 漫反射做插值，調整風格化程度。 |
| 風格化鏡面高光 | PBR 高光的衰減太柔時，亮點缺少卡通色塊的邊界。 | 保留 Unity 的 BRDF 鏡面項，再對強度重映射。以閾值控制亮區大小，用過渡寬度控制邊緣銳利程度。 |
| 可調明暗側的 Fresnel 邊緣光 | 角色輪廓需要亮邊，但亮面與背光側若一律加亮，容易削弱光照方向。 | 用法線與視線的點積找掠視角，再用 N·L 調整受光側與背光側的亮度。以 Smoothstep 控制亮邊由硬切到柔化的過渡。 |
| 裁切空間的背面外擴描邊 | 作者用深度、法線和頂點色做邊緣偵測時，仍難以控制想要的線條。 | 額外繪製一次模型，在裁切空間外擴頂點、剔除正面，以原模型外側露出的部分形成外線。作者在 URP 以 Renderer Feature 找到指定 Shader Tag 的描邊 Pass 並安排繪製時機。 |
| Kajiya–Kay 各向異性髮光 | 一般鏡面高光以表面法線為主，難呈現受髮絲方向影響的亮帶。 | 用髮絲切線和光照半向量計算高光，透過貼圖沿法線偏移切線，再調整高光的邊界過渡。 |

## 印刷感與材質工作流

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| SDF 半色調網點 | 用平滑陰影表現層次，缺少漫畫或報紙的印刷質感。模型 UV 也可能把規則的墨點拉歪。 | 用帶正負號的距離場（SDF）定義點形，以 N·L 改變點大小。模型 UV 讓網點跟著表面變形，螢幕座標可維持版面式排列。作者在螢幕座標版本加入鏡頭到模型根節點的距離縮放，補償遠近造成的密度變化。 |
| 用單張雜訊疊出素描排線 | 每個明暗級別都準備一張不同密度的筆觸貼圖，會增加素材製作量。 | 拉伸一張雜訊貼圖成筆觸，多次用不同 UV 偏移和縮放取樣後疊加。依 N·L 決定疊加層數，讓暗區排線更密。做法以多次即時取樣換取較少的專用貼圖。 |
| 自訂材質編輯器 | 光照、描邊和筆觸等參數放在同一個材質面板，設定多時難以查找。 | 繼承 BaseShaderGUI，沿用 Unity 有的材質屬性介面，再為特殊設定加上自訂 Drawer。 |
