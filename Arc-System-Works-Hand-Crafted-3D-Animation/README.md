# Arc System Works 三渲二短片筆記

原始影片由「Mr.斯宾奇」上傳。[日本最强3渲2游戏公司？逐帧制作3D堪比手绘！制作过《龙珠斗士Z》，这到底什么神仙公司？！](https://www.bilibili.com/video/BV1P4411M7k1/)

這是一支以遊戲畫面與畫面文字介紹 Arc System Works 的短片。時間碼可回看指定畫面。本機字幕擷取中文解說文字，預告片的日文台詞與音樂段落保留在原影片。

## 技術與時間碼

| 影片時間 | 技術 | 解決的問題與做法 |
| --- | --- | --- |
| [00:10](https://www.bilibili.com/video/BV1P4411M7k1/?t=10) | 三渲二與遊戲演出 | 開頭剪接的《Xrd》與《龍珠鬥士Z》畫面可以比較模型在側視戰鬥和特寫中的變化。3D 場景讓攝影機可切換角度，明暗色塊和輪廓繼續維持動畫感。 |
| [00:36](https://www.bilibili.com/video/BV1P4411M7k1/?t=36) | 《碧藍幻想 Versus》成品參考 | 片頭較長的預告段落適合看插畫角色如何從角色展示轉到戰鬥，再以近景和特效強調技能。這部分是成品畫面，片中沒有展示著色器節點。 |
| [02:41](https://www.bilibili.com/video/BV1P4411M7k1/?t=161) | 2D 精靈與 3D 場景的混合 | 《蒼翼默示錄》的例子用 3D 場景支援舞台空間，角色則以 2D 精靈控制畫面。這能維持手繪剪影，但角色轉鏡的自由度主要受既有畫格限制。 |
| [03:13](https://www.bilibili.com/video/BV1P4411M7k1/?t=193) | 利用 3D 攝影機做必殺技構圖 | 3D 模型可支援跨角度取景。為了讓技能起手與衝擊清楚，演出可以在戰鬥廣角與表情、手部等局部特寫間安排切換。 |
| [03:24](https://www.bilibili.com/video/BV1P4411M7k1/?t=204) | 為特定鏡頭縮放模型部件 | 固定比例的手腳在近景有時不夠有力。影片指出 ARC 依鏡頭修改局部比例，讓朝鏡頭伸出的部位形成更清楚的透視與剪影。 |
| [03:27](https://www.bilibili.com/video/BV1P4411M7k1/?t=207) | 逐姿勢打關鍵影格 | 自動插值會填滿動作之間的過渡，但每格的剪影未必符合手繪構圖。逐姿勢設計可以分開控制蓄力、揮動和命中的形狀。 |
| [03:34](https://www.bilibili.com/video/BV1P4411M7k1/?t=214) | 按姿勢控制停格 | 影片把手繪節奏形容為抽幀。《Xrd》原講描述的做法是停留手調姿勢、取消關鍵影格間的平滑插值。這影響角色動作節奏，遊戲顯示更新仍可維持流暢。 |
