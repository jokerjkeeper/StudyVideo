# Blender 模型直繪與材質貼圖｜Noggi

原始工具頁｜[The 2D Artist's 3D Kit](https://noggi3d.gumroad.com/l/2dkit)

這個 Blender 外掛把畫筆、圖層和遮罩帶進模型直繪流程。原商品頁這次未能直接讀取，以下依公開的功能說明與示範紀錄整理。[Noggi 介紹影片](https://www.youtube.com/watch?v=ptX2Mf6pjDw) · [示範與流程紀錄](https://modelingtechnote.com/2026/11/13/2d-artists-3d-kit-blender/) · [功能索引](https://blendatlas.com/products/the-2d-artists-3d-kit)

| 技術或工具 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 自動建立繪製所需的材質與貼圖 | UV 展開、材質接線與貼圖建立會讓繪圖者尚未試色就先卡在設定。 | 選取模型後直接開啟繪製工作階段，將準備工作交給外掛。已有製作規範的模型可以沿用自訂 UV。 |
| 畫筆、圖層與剪裁遮罩 | 陰影、腮紅和細節直接畫死在同一層時，改色容易破壞底稿。 | 將不同筆觸分層，以圖層遮罩或剪裁遮罩控制範圍，並可用填色、模糊、塗抹等工具修整邊界。 |
| 多通道繪製 | 同一區域的顏色、粗糙度與發光需要不同控制，例如亮色布料也可能很粗糙。 | 分別繪製色彩、粗糙度、金屬度、透明度與發光，將材質反應與底色分開維護。 |
| 自訂 UV、UDIM 與材質分組 | 多物件或高細節角色常需要有計畫地分配貼圖空間。 | 可指定哪些物件共用貼圖，也可使用自訂 UV 和 UDIM 磚塊，保留對貼圖配置的控制。 |
| 在姿勢下繪製 | 只看預設姿勢時，難以看出表情或動作中的遮蔽和接縫。 | 可在擺好姿勢或有動畫的模型上直接畫，方便對照最終構圖。 |
| 將繪製結果輸出為貼圖 | 即時繪製狀態需要轉成可交付、可重用的材質貼圖。 | 先選解析度，再用 Save Paint as Textures 匯出。結束繪製工作階段會清除工作中建立的圖層，輸出前要確認已保留需要的結果。 |
