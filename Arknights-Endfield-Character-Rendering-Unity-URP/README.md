## 共用著色與服裝

| 技術 | 解決的問題 | 作者的復刻做法 |
| --- | --- | --- |
| 直射日光強度與雙狀態著色 | 角色到了陰處，如果只是把同一盞主光變暗，原本的主光方向感和亮邊仍可能過於明顯。 | 用直射日光權重混合亮處與陰處的著色反應，減弱直接光造成的方向性和亮邊，讓角色更貼近環境。 |
| 三段 Toon Ramp 與背光補償 | 衣料要保留清楚的插畫色階，背光時也要看得到大形。 | 對不同服裝使用各自的 Ramp，分開設定光照分布和顏色，再補償背光側的明暗範圍。 |
| 風格化 PBR 高光與環境鏡面近似 | 衣服和金屬配件需要不同的反光層次，整件套用同一亮點會混在一起。 | 分別調整直接鏡面高光與環境鏡面項，用材質通道控制金屬度、反射率和光滑度。作者用函數近似部分 IBL 計算。 |

## 皮膚、臉、眼睛和頭髮

| 技術 | 解決的問題 | 作者的復刻做法 |
| --- | --- | --- |
| 皮膚暗部 LUT 與 Fresnel 透光近似 | 臉、頸與手腳的暗色容易不一致，皮膚邊緣也可能顯得太硬。 | 以 LUT 統一暗部配色，用視角與法線關係控制邊緣染色，近似皮膚透光感。皮膚材質移除衣料用的 IBL 鏡面項。 |
| SDF 臉影與臉頸遮罩 | 臉部法線若直接決定二值明暗，暗形容易破碎，臉與脖子也可能亮暗分離。 | 以臉部局部座標和光向查 SDF，決定左右臉的暗形。臉頸交界用區域遮罩混合臉部 SDF 與原本的模型著色，另以分格表情貼圖疊加局部細節。 |
| 眼部自訂法線與 MatCap | 虹膜需要曲面受光和集中高光，平面模型或一般鏡面項難直接給出所需亮形。 | 由眼部 UV 構造近似半球法線，計算受光並取樣 MatCap，用遮罩只在指定眼球區域加亮。 |
| 平滑法線與各向異性髮光 | 每束頭髮各自產生高光時，髮型的大亮帶容易碎裂。 | 為高光另用平滑法線與高光色圖，疊加方向性的髮絲高光。漫反射維持原模型的表面法線。 |
| 平滑法線描邊 | 模型接縫與硬邊容易把外擴輪廓撐裂。 | 從附加 UV 與切線基底還原平滑外擴方向，投影到螢幕平面再做偏移。作者把線條著色沿用基礎漫反射。 |
| 重疊殼層近似裙襬絨毛 | 要表現裙襬短毛的厚度與輪廓，直接建每根纖維的代價高。 | 以多層實例／Pass 配合形狀圖近似絨毛，利用雜訊塑造局部效果。作者指出復刻結果與遊戲仍有明顯差異。 |
