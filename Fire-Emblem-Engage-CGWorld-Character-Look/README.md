# 《聖火降魔錄 Engage》角色與場景渲染

原文（CGWORLD，2023-11-20）｜["実在感"のあるルックでキャラクターを魅力的に見せる『ファイアーエムブレム エンゲージ』](https://cgworld.jp/article/202311-cgw303-fee.html)

CGWORLD 訪問 Intelligent Systems 的開發團隊。遊戲在 Nintendo Switch 上以 Unity 製作，目標是保留角色原案的高彩度與賽璐璐風格，同時讓衣料、金屬、瞳孔與背景帶有足夠的材質層次。

## 角色著色

| 技術 | 解決的問題 | 做法 |
| --- | --- | --- |
| 分層瞳孔 Shader | 近景要保留插畫式的眼睛設計，角色也可能有不同的虹膜符號。 | 將瞳孔拆成最多四層遮罩貼花，每層可獨立設定顏色和動態。特殊虹膜標記可透過替換遮罩製作，部分遮罩的 UV 會隨時間擺動，形成閃爍。 |
| 背面外擴描邊 | 全身使用同一線寬和顏色，容易讓五官、髮束和衣裝的輪廓顯得一樣重。 | 以背面法畫輪廓，頂點色 R 通道控制各處的線寬。描邊色取樣附近的貼圖顏色再調色，讓線條與局部配色相容。 |
| 眉毛與睫毛的前景顯示 | 瀏海遮住五官會讓表情難辨，但遮住眼睛也可能是角色原案的一部分。 | 讓眉毛、睫毛可顯示在瀏海前方，再按角色設計指定各部位的透明度。 |
| 法線貼圖搭配 Toon Ramp | 大面積平塗容易令衣料缺少質感，整片加強紋理又會讓亮部太密。 | 讓服裝法線細節主要在明暗交界處顯現，亮面減少細節。金屬另外用手繪 Ramp 控制明暗形狀，保留插畫式的起伏。 |
| 材質預設切換 | 戰鬥中的 Engage 狀態需要改變角色外觀，完整複製模型會增加資產維護量。 | 保留同一模型，切換材質預設。材質同時使用底色、法線、打包的粗糙度和金屬度，以及風格化 Ramp。 |

## 場景、光影與特效

| 技術 | 解決的問題 | 做法 |
| --- | --- | --- |
| 背景以 PBR 混合 Toon Ramp | 寫實背景和賽璐璐角色的明暗語言不同，站在一起容易有割裂感。 | 以 PBR 材質保留表面質感，再按物件調整 Toon Ramp 和邊緣光的混合程度。 |
| 遠景地表底色投影 | 重複鋪設的近景地表紋理在遠處會露出週期性圖案。 | 把俯視取得的地形底色按距離混入地表材質，弱化遠景的細節與重複感。 |
| 場景分區剔除與 LOD | 據點物件與角色多，繪製整張地圖會增加負載，統一切換距離也容易讓個別物件太早換模。 | 將據點分成約四十個剔除區域，合併一部分背景物件，並由設計師調整特定資產的 LOD 切換距離。 |
| 混合光照與角色投影代理 | 靜態地面可保存烘焙光照，但移動角色經過建物時也要讀得到場景陰影。 | 直接光即時計算，間接光使用 Lightmap。讓簡化的建物代理網格負責投射角色陰影，並以 Maya 工具批次生成代理。 |
| 動態展開斬擊網格 | 攻擊可以快速完成，斬擊仍需留下連續弧線，並在不同視角下維持厚度。 | 預先計算動畫曲線，用它展開製作好的厚度網格。戰鬥特效也可用 Cutout 消失，維持和角色相近的清晰邊界。 |
