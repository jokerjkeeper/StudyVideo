# 《罪惡裝備 Xrd》與《龍珠鬥士Z》的動畫節奏

原始影片由 New Frame Plus 上傳。時間碼對應以下 YouTube 版本。[The Animation of Guilty Gear Xrd & Dragon Ball FighterZ](https://www.youtube.com/watch?v=kZsboyfs-L4)

New Frame Plus 從動畫師角度比較兩款遊戲。技術重點是控制哪些部位要動、姿勢停留多久，以及如何把快速動作畫得清楚。兩作的差異是影片作者對成品的觀察。

本機字幕為原作者提供的英文字幕，另附 YouTube 繁中自動翻譯。

## 技術與時間碼

| 影片時間 | 技術 | 解決的問題與做法 |
| --- | --- | --- |
| [04:40](https://www.youtube.com/watch?v=kZsboyfs-L4&t=280s) | 用 3D 姿勢當 2D 作畫參考 | 影片回顧 Arc System Works 早期像素動畫流程。先雕塑並擺好 3D 姿勢，像素畫師再依其形體與透視作畫，可加快製作，也能讓不同人畫得一致。 |
| [05:10](https://www.youtube.com/watch?v=kZsboyfs-L4&t=310s) | 賽璐璐著色與專屬打光 | 角色需要有動畫般的暗面形狀，又要在戰鬥鏡頭裡清楚可讀。角色美術以可調的著色方式重新安排明暗，並以專屬光照呈現個別角色。 |
| [08:30](https://www.youtube.com/watch?v=kZsboyfs-L4&t=510s) | 階梯式關鍵影格 | 平滑補幀會吞掉擺姿勢的節奏。每個姿勢可以保持指定時間，接著直接換到下一張，模擬有限動畫的曝光與換畫方式。 |
| [09:50](https://www.youtube.com/watch?v=kZsboyfs-L4&t=590s) | 局部維持、局部更新 | 整個角色一起動容易讓焦點分散。保持軀幹不動，同時讓頭髮、衣料等局部繼續動，既看得出角色在表演，又能保留手繪的停格感。 |
| [10:10](https://www.youtube.com/watch?v=kZsboyfs-L4&t=610s) | 手修比例與誇張透視 | 每格都維持一致的幾何比例，快速動作也容易保留僵硬的 3D 感。手調臉部、手腳尺寸與剪影可強化單格動作。若變形太大，影片也舉出直接換模型的例子。 |
| [11:50](https://www.youtube.com/watch?v=kZsboyfs-L4&t=710s) | 2D 動態貼圖與逐格 3D 特效 | 擊中和速度要在很短時間內看得懂。速度線與打擊特效可用 2D 動態貼圖。一些需要體積輪廓變化的揚塵，則用逐格製作的 3D 形狀。 |
| [14:20](https://www.youtube.com/watch?v=kZsboyfs-L4&t=860s) | 速度線代替大塊拉伸過渡 | 作者觀察《龍珠鬥士Z》更常用傳統速度線來表現移動方向，並對照《Xrd》拉長變形的形體。回看時可逐格分辨速度資訊是由線條還是角色剪影傳達。 |
| [14:40](https://www.youtube.com/watch?v=kZsboyfs-L4&t=880s) | 以長停格和選擇性動作貼近原作 | 《龍珠鬥士Z》有些段落保持整體姿勢，只更新嘴部等局部。影片用《Xrd》Sol 待機時細緻的胸口與皮帶變化做對照，說明兩作刻意使用不同的細節量。 |
