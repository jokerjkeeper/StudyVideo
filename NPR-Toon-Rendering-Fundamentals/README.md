# 三渲二基礎：描邊與卡通著色

原始影片由「Paper朱」上傳。[一个视频彻底了解三渲二！NPR/卡通渲染的基本原理 构成篇](https://www.bilibili.com/video/BV1eY411b75h/)

Paper朱 從描邊和著色兩條線解釋非寫實渲染。先比較四種線條的適用範圍，再看色帶、冷暖色與局部門檻如何改變明暗。片中的商業遊戲案例有些是作者分析。

本機附中文轉錄字幕及帶時間碼的文字稿。字幕依語音轉錄，重要術語已校正，個別口述仍可能有辨識誤差。

## 技術與時間碼

| 影片時間 | 技術 | 解決的問題與做法 |
| --- | --- | --- |
| [00:24](https://www.bilibili.com/video/BV1eY411b75h/?t=24) | 線條與著色是兩個控制層 | 三渲二需要讓角色的形狀和明暗像插畫。先決定哪些邊界要畫線，再決定亮暗如何變成色塊。外輪廓、表面內線和明暗分界可以使用不同做法。 |
| [01:18](https://www.bilibili.com/video/BV1eY411b75h/?t=78) | 以法線與視線找輪廓 | 表面法線和視線接近垂直時，該表面在視覺上接近剪影。可用兩者內積與閾值決定著色區域。直接把區域塗黑可快速產生輪廓感，但線寬容易受網格曲率及視角影響。 |
| [02:14](https://www.bilibili.com/video/BV1eY411b75h/?t=134) | 背面外擴（Inverted Hull） | 在原模型外加一層沿法線外擴的網格，只畫背面，露出的邊緣形成線。可以逐頂點控制厚度，但硬邊的法線分裂會造成開縫，需要特別準備外擴方向。 |
| [03:39](https://www.bilibili.com/video/BV1eY411b75h/?t=219) | 螢幕空間深度／法線邊緣檢測 | 模型之間或表面摺角有時需要畫內線。比較相鄰像素的深度或法線差異可畫出物體邊緣與內部結構，也較容易指定像素線寬。門檻、解析度和不在緩衝區中的資訊都會影響結果。 |
| [04:44](https://www.bilibili.com/video/BV1eY411b75h/?t=284) | 軸對齊 UV 內線（本村線） | 衣物的縫線和部件邊界在特寫會放大斜向貼圖的鋸齒。沿 U 或 V 軸畫色條，再調整 UV 與色條的重疊來控制線寬，代價是要為線條手工調整 UV。 |
| [05:13](https://www.bilibili.com/video/BV1eY411b75h/?t=313) | 賽璐璐著色與一維 Ramp | 直接使用連續受光值會產生柔滑的 3D 漸層。把法線與光向的內積映射到美術繪製的 Ramp，以少量色塊決定亮暗與交界硬度。 |
| [05:46](https://www.bilibili.com/video/BV1eY411b75h/?t=346) | 用第二維容納視角效果 | 只用受光量查一維色帶，無法獨立描述隨視角改變的邊緣效果。影片提出把 Ramp 擴成二維，把視線與法線的關係放入另一個查表座標。 |
| [06:03](https://www.bilibili.com/video/BV1eY411b75h/?t=363) | 冷暖色調著色（Tone-Based Shading） | 只用灰階明暗難以表達插畫的色溫。由美術設定冷、暖兩端，再按受光方向插值。連續色溫適合技術插畫，也可以再切成色塊以維持日式動畫感。 |
| [06:45](https://www.bilibili.com/video/BV1eY411b75h/?t=405) | 局部閾值與暗部色彩 | 統一的閾值會讓不同部位同時入陰。頂點資料可讓特定部位提早或延後變暗，另外讓暗面吃到獨立的色彩或暖色補償。這一段是影片對案例的整理。 |
| [07:27](https://www.bilibili.com/video/BV1eY411b75h/?t=447) | 分開控制漫反射與高光 Ramp | 漫反射色帶和高光色帶有不同任務。把亮暗邊界安排在 Ramp 上便於集中控制的區段，可保留硬邊和暗部內的變化。片中《原神》素材的解讀屬作者分析。 |
| [08:16](https://www.bilibili.com/video/BV1eY411b75h/?t=496) | 四通道分層雲 | 要用少量的雲模板做出多種雲層氣氛，可讓不同通道分別承載基礎光、兩層暗面和邊緣光，再按時段調色。這是影片引述的《崩壞3》案例。 |
