原始影片由「让你爱上学习」上傳。下方時間碼對應這個 B 站版本。[终末地有多少个人在做？终末地评测：渲染与商业化](https://www.bilibili.com/video/BV1de411f7qe/)

這支影片是早期技術測試的第三方評測，主要討論場景與角色如何維持各自的質感，以及頭髮高光、半透明遮擋和陰影能透露什麼。以下的實作方法是用來分析這些效果的通用做法。《終末地》實際使用的材質、著色器與渲染管線，仍需開發者資料才能確認。[B 站原影片](https://www.bilibili.com/video/BV1de411f7qe/)

## 如何做同條件對照

1. **比較光照與材質。** 用同一角色、同一鏡頭，在直射光、陰影、室內三種環境切換。固定曝光後，分別比較臉部色階、衣物高光與角色輪廓，看是哪一項讓角色在暗處仍然可讀。
2. **拆開頭髮的三個問題。** 先用固定頭型分別轉燈與轉鏡頭，追蹤亮帶。再讓瀏海逐步蓋過眉眼，觀察可見範圍是否連續變化，最後播放頭部動作，看臉上的陰影是否跟著移動。
3. **控制近景與戰鬥的比較條件。** 若要判斷是否用了高低模，需先對齊鏡頭距離、燈光、姿勢與畫質。可用的工程證據包括網格資料、LOD 切換紀錄或繪製擷取。

## 技術參考

- Unity URP Lit 文件將鏡面高光、Emission、Alpha Clip、投射陰影與接收陰影分別定義，可用來對照影片裡幾種容易混在一起的效果。[Unity URP Lit Shader Graph](https://docs.unity3d.com/en/current/Manual/urp/prebuilt-shader-graphs-urp-lit.html)
- Unity 專案的管線由專案與畫質設定決定，這是判斷 Built-in 或 SRP 時可檢查的具體資料。[Unity 渲染管線設定](https://docs.unity3d.com/6000.1/Documentation/Manual/srp-setting-render-pipeline-asset.html)
- 《原神》主機版的開發者簡報提供另一個可核對的案例。它同時使用 PBR 光照基礎與美術指定的材質光照模型，可用來理解風格化與物理光照如何並存。[Unity 官方簡報第 9–12 頁](https://www.docswell.com/s/UnityJapan/KWRPQ5-210617-unity-dojo20211mihoyozhenzhongyi#p9)
