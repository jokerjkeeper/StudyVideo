# 米哈遊行動端卡通渲染｜《崩壞3》與即時 CG

原文｜[米哈游技术总监首次分享：移动端高品质卡通渲染的实现与优化方案](https://zhuanlan.zhihu.com/p/37001473)

筆記依遊戲葡萄整理的賀甲在 Unite 2018 的講演紀錄撰寫。分享前段介紹《崩壞3》的行動端做法，後段介紹面向即時動畫 CG 與更高規格平台的做法。[GameRes 刊載版](https://www.gameres.com/807189.html) · [Unity Korea 的原講影片](https://www.youtube.com/watch?v=egHSE0dpWRw)

## 《崩壞3》行動端

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 降解析度的平面反射 | 金屬地面需要映出角色和場景，完整重畫一次的成本太高。 | 用鏡射相機畫低解析度反射，簡化材質、跳過次要小物件，再用模糊、法線擾動和 Fresnel 調整材質感。離開主反射平面的次要表面以環境貼圖表現。 |
| 將畫面扭曲合併到最終後處理 | 刀光、水流和時空特效需要擾動背景，單獨處理會增加行動端的畫面讀寫。 | 把兩軸 UV 位移及強度遮罩存到三個通道，最後合成時擾動畫面。這樣可共用合成流程，但深度層次處理有限，前景偶爾也會受到後方扭曲影響。 |
| 多尺度 HDR Bloom 與色調映射 | 高亮粒子需要有不同大小的光暈，全解析度模糊和多次合成開銷過大。 | 先從降採樣後的 HDR 畫面取出高亮，逐級縮圖模糊後疊加，再把效果、曝光及色調映射合併到最終 Pass。 |
| 以通道遮罩重組雲層光照 | 為每個時刻準備整套雲圖會增加資產量，也難調整光色。 | 把基礎受光、兩層陰影和邊緣光分成四個通道，以時間關鍵幀改色。用粒子組成雲海，調整發射分布以控制重複感和透明粒子重疊繪製。 |
| Lighting Volume 與分段霧效 | 角色經過陰影區時要融入環境，遠景和前景也需要不同的霧色與強度。 | 用方向光控制主色，用關卡手工放置的 Lighting Volume 表現局部受光變化，並按深度分開調整遠近霧效。 |
| 分層相機景深 | 選角畫面需要突出清晰的角色，但不一定需要一般景深的連續深度過渡。 | 用獨立相機畫背景，縮圖後以六角取樣模糊，再與清晰前景合成。模糊越大時可使用越低的背景解析度。 |

## 即時動畫 CG 與高規格渲染

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 多通道 2D Ramp | 純粹壓暗容易讓陰影失去色彩，整個角色用同一陰影硬度也限制手繪造型。 | 用 RGB 通道記錄不同陰影層的權重，逐層指定色彩。沿另一個採樣軸選擇硬邊或柔邊的 Ramp，並用繪製的遮罩逐像素控制。 |
| 眼球折射與焦散 | 眼睛近景尤其是側面，需要表現虹膜位於眼球表面之下，並帶有受光變化。 | 隨視角計算折射後的虹膜取樣位移，再以入射方向、Fresnel 和焦散貼圖控制風格化亮斑。 |
| 雙層各向異性髮光 | 規則的鏡面高光難畫出跨髮束的亮帶及髮絲細節。 | 用切線計算高光，混合較寬的亮帶與高頻細節。Flow Map 可整理方向，Jitter Map 擾動切線使亮帶出現細絲變化。 |
| 透明材質的背景取樣 | 水晶和薄紗只做 Alpha 混合會缺少折射、色散或模糊。 | 用 Command Buffer 取得已繪製背景。水晶用 RGB 取樣偏移差表現色散，薄紗取樣分級模糊背景，並利用代理網格限制處理區域。 |
| 依位置選擇描邊方法 | 只靠背面外擴會漏掉硬表面的內部折線，螢幕空間描邊則不易在角色近景精細控寬。 | 角色用平滑外擴法線和頂點色調整輪廓，尖銳折線預先提取成額外網格。場景邊緣則可用畫面上的深度與法線差偵測。 |
| Blue Noise 與時間抗鋸齒 | 體積光加入光形貼圖後會有高頻細節，取樣不足時容易走樣。 | 用 Blue Noise 抖動取樣，再配合 Temporal AA 累積，講者比較後可用較少樣本維持效果。 |
| 可調色的動態 AO | 遮蔽能加深角色的接觸細節，但單純乘灰容易讓鮮豔配色變髒。 | 改造 HBAO，在遮蔽區域調整色相與飽和度，讓暗處與整體配色一致。 |
