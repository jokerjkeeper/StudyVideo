# 商業遊戲描邊技術總覽（下）

原文（Ashley，網易遊戲學堂，2021-12-13）｜[描边技术总览和常见商业游戏中的描边方案（下）](https://api.academy.163.com/course/careerArticle?course=770)

上篇討論用模型與表面方向產生線條。下篇處理兩種需求：讓內線固定在模型表面，以及從已繪製的畫面產生輪廓。[上篇筆記](../Game-Outline-Techniques-NetEase/README.md)

## 貼圖與模型內線

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 直接在貼圖畫線 | 衣褶、縫線等細節需要由美術自由定形，且隨角色一起變形。 | 在線條所在的表面貼圖畫出輪廓。適合鏡頭少拉近的小細節和難以規則化的圖案。細斜線近看容易鋸齒或模糊，可調整 UV 使線段沿 U／V 軸排列，或為線稿另給貼圖解析度和 UV。 |
| 本村線 | 直接把粗細變化畫進貼圖，斜向邊界放大時容易顯露像素。 | 以貼圖中與 U／V 軸對齊的深色邊帶作為線色。讓同位置的分割頂點具有不同 UV，再調整三角形覆蓋深色邊帶的比例來控制線寬。近景線形較乾淨，但需要專門整理拓撲和 UV。 |
| 類本村線 | 要有清晰的內線，但製作流程難以逐段微調本村線的 UV。 | 把線形直接切進模型表面的拓撲，將該區 UV 指向單一深色塊。線寬由幾何決定，可直接看模型調整，但要為線條保留幾何，改線形時得回去修模型。 |
| SDF 貼圖內線 | 傳統線稿放大容易受原始像素格限制，模型也可能難以重新整理 UV。 | 離線把內線遮罩轉成有正負號的距離場，渲染時依距離閾值重建線形，並控制邊緣過渡。多一次貼圖取樣，精度仍受距離場解析度與取樣影響。這是 Ashley 提出的方案，文中未確認商業遊戲採用案例。 |

《罪惡裝備 Xrd》的本村線可對照角色內線投影片。Valve 的距離場技術則說明如何用距離資料在放大時重建較清晰的邊界。[Arc System Works GDC 簡報，第 25 頁](https://media.gdcvault.com/gdc2015/presentations/Motomura_Junya_GuiltyGearXrd.pdf#page=25) · [Valve 距離場論文](https://cdn.akamai.steamstatic.com/apps/valve/2007/SIGGRAPH2007_AlphaTestedMagnification.pdf)

## 螢幕空間描邊

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 深度與法線的 Sobel 邊緣偵測 | 場景物件很多時，逐一做外擴線條成本高，硬表面轉折也需要內部結構線。 | 對相鄰像素的場景深度與法線計算梯度。深度突變可找遮擋邊界，法線突變可補表面折角。偵測階段的主要開銷取決於解析度和取樣數，輸入沒有明顯差異的線可能被漏掉。 |
| 後處理線寬與線色資料 | 單一閾值和顏色難以照顧不同物件，調低閾值也可能多畫出不需要的邊。 | 閾值控制哪些邊被選中。若要局部控制，原文建議將線寬或色彩識別資料寫入像素資料供後處理讀取。線色可以取底色，也可以用整數索引查調色盤，減少逐像素儲存 RGB 所需的資料量。 |
| JFA 外輪廓 | 需要很寬、沿可見剪影等距展開的外線，背殼外擴很難維持這種像素寬度。 | 將目標遮罩轉成螢幕空間的無號距離場。Jump Flooding Algorithm（JFA）逐輪縮小跳距，近似找出每像素最近的種子。再用距離閾值從遮罩外側選出線帶，並在邊緣做平滑過渡。低解析度或近似誤差仍可能造成鋸齒、區塊或閃爍。 |
| JFA 合成時檢查遮擋 | 單用距離閾值可能把輪廓畫到更前方的物件上。 | Ashley 提議在傳遞最近種子的同時保留其深度。合成時用距離決定寬度，再比較種子與目前場景深度，抑制被前景遮住的線段。這個延遲管線方案需要額外的目標遮罩與深度資料。 |

原文以《二之國 2》的逐幀分析作為後處理描邊案例，JFA 的寬外線則可對照 Rong 與 Tan 的距離轉換，以及 Ben Golus 的實作比較。[《二之國 2》逐幀分析](https://blog.thomaspoulet.fr/ninokuni2-frame/) · [JFA 原論文](https://doi.org/10.1145/1111411.1111431) · [寬描邊實作](https://bgolus.medium.com/the-quest-for-very-wide-outlines-ba82ed442cd9)
