# 網易 TA 卡通渲染筆記｜明暗、描邊與 PBR

原文｜[网易TA大咖带你走近卡通渲染，讲解关于Trick的两三事](https://developer.unity.cn/projects/6180d69bedbc2a06d1042cf3)

雷宇航（網易技術美術）在「Unity 大咖作客」示範如何讓角色具備清楚的卡通明暗，同時保留材質和環境之間的光照反應。筆記依遊戲葡萄刊載的講者節選整理。[文章刊載版](https://www.sohu.com/a/499030117_204824) · [Unity 中文課堂的完整分享入口](https://learn.u3d.cn/tutorial/cel-shading-trick)

## 明暗與輪廓

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| Step、Smoothstep 與 Ramp | 連續的漫反射漸層難以維持賽璐璐需要的清楚色塊。 | 重新映射法線和光向的點積 N·L。Step 控制分界位置，Smoothstep 留出可調的過渡區，Ramp 還能把不同明度對應到指定色相。 |
| Fresnel 型邊緣光 | 角色輪廓容易融入背景，需要沿掠視角出現的亮帶。 | 用法線與視線的點積 N·V 找出掠視角區域。亮帶跟隨表面法線，厚度也會隨幾何曲率變化。 |
| 深度偏移邊緣光 | 平坦表面與硬轉折處，基於 N·V 的亮帶不容易畫出均勻的窄線。 | 比較偏移位置與原表面的深度，用深度差選出亮帶，可得到較均勻的硬邊效果。 |
| 明暗交界染色 | 大面積亮暗色塊之間缺少插畫常見的窄色帶。 | 直接把色帶畫在 Ramp 上，或把方向相反的兩個 Smoothstep 相乘，圈出明暗交界的窄區域再著色。 |
| 背面外擴描邊 | 剪影需要穩定的外輪廓，硬邊拆分的法線可能使外擴後的線條斷開。 | 繪製沿法線外擴的背面。另存一組平滑法線供描邊使用，讓材質著色可以保留原本的硬邊。 |
| Sobel 搭配純色區域 | 對完成畫面直接偵測邊緣容易把表面花紋視為輪廓。 | 將預計勾線的區域先畫成純色塊，再執行 Sobel 邊緣偵測，讓輸出集中在指定色塊的交界。 |
| 本村線 | 斜畫在貼圖上的細線容易因取樣而模糊或出現鋸齒。 | 將要畫內線的模型 UV 拉直，使線條沿 U 或 V 軸排列，換取較清晰的取樣。代價是資產需要專門整理 UV。 |
| 依拓撲偵測輪廓 | 某些風格需要直接取得網格輪廓再設計線條形狀。 | 從模型拓撲辨識輪廓邊，取得能進一步加工的線段。講者指出這類方法成本較高，常用於離線渲染。 |

## 把卡通控制加到 PBR 的計算環節

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 在直接光前重映射 N·L | 預設光照的轉折不一定符合臉部或瀏海陰影的設計。 | 在光照資料準備階段合成二值明暗、面部遮罩及髮部投影，再把結果交給後續光照計算。 |
| 重塑直接鏡面高光 | 傳統 GGX 高光的範圍或形狀未必符合髮束與服飾的造型。 | 重映射法線分布項的高光範圍，或加入各向異性、遮罩和偏移，控制亮帶的寬度、方向與位置。 |
| 依部位調整間接光 | 場景間接光能讓角色融入環境，但臉部受到太多間接光會削弱平面色塊感。 | 降低臉與皮膚的間接光權重，其他區域保留材質與場景光照的反應。 |
| 用獨立亮層表現眼睛和亮邊 | 眼睛亮點、MatCap 和邊緣光需要有穩定的構圖位置與可控亮度。 | 把這些項目當作自發光疊入。講者的示範會比原始 PBR 更亮，強度需要按畫面效果調整。 |
