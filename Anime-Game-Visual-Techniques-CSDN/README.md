# 《罪惡裝備 Xrd》卡通渲染｜頂點資料與線條

## 角色著色

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 幾何細節與頂點資料 | 特寫時，依賴貼圖的細節和遮罩一放大就容易暴露像素。 | 重要細節直接建模，著色控制主要存於頂點法線、頂點色和 UV。頂點間可插值，代價是需要足夠的網格密度與製作時間。 |
| 頂點色偏移明暗閾值 | 同一閾值會讓應保持暗色的縫隙或遮蔽部位，和周圍一起轉亮。 | 在頂點色通道繪製閾值偏移，讓指定區域在相同光向下更容易進入陰影。控制的是明暗切換，而非在最後疊上一層灰色。 |
| 手修頂點法線 | 二值光照會將小幅法線變動放大為大片亮暗跳變，尤其會破壞臉部暗形。 | 直接修整著色用的頂點法線，在預覽畫面對照亮暗邊界，維持原本的幾何剪影。 |
| 每角色獨立光向 | 共用場景光源時，陰影可能在待機姿勢或特寫角度遮住眼神和輪廓。 | 為每個角色選擇適合待機構圖的主光方向。過場可讓光向跟著鏡頭和姿勢變化。 |
| Base Texture × Tint Texture | 只降低亮度會讓皮膚與服裝的暗面缺少各自的色彩特徵。 | Base Texture 定義亮部，暗部乘上各材質的 Tint，讓美術分別控制陰影的深淺與色相。 |

## 描邊與演出

| 技術 | 解決的問題 | 做法與取捨 |
| --- | --- | --- |
| 背面外擴與局部線寬 | 同一個外擴量難以應付不同鏡頭距離與不同大小的角色部位。 | 外擴網格後繪製背面，以鏡頭距離及頂點資料調整寬度，並用深度偏移調整線條與相鄰表面的疊合。 |
| 本村線與 UV 軸對齊 | 斜畫在貼圖上的內線在特寫容易顯露鋸齒。 | 將色塊與線條排成對齊 U、V 軸的矩形，在色塊間保留深色區。調整網格 UV 覆蓋深色區的比例來控制線寬。做法適合可容許 UV 拉伸的大面積純色。 |
| 手調關鍵姿勢與階梯式播放 | 均勻的插值會沖淡招式的停頓與形變，讓演出偏離手繪動畫節奏。 | 由動畫師設定姿勢、停格與骨骼縮放等變形，讓指定姿勢維持數幀再跳到下一個姿勢。過場光向也可以獨立調整。 |
